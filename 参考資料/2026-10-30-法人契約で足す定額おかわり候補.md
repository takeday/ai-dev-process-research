## 課題感（この資料の前提）

- **法人契約**であること。
- 3つ目のエージェントに求めるのは、Claude や Codex と**性能の違うもの**ではなく、**Claude・Codex の Premium（$125/月）でも足りない場合の「おかわり」**。複数を併用して使用量を分散し、長く使えるようにしたい。
- **定額制**であること。従量課金よりコストを下げやすく、予測もしやすい。
- 判断基準は、Codex を導入したときと同じ。**「Claude の超過利用で $100 分を買うより、Codex Premium（$125）の定額席のほうが多く使える」**から Codex を選んだ。3つ目も「**席料金を上回る量が付いた、法人で契約できる定額の席か**」で評価する。
- Claude に $125 より上の法人向け定額プランがあれば、最初からそれを選んでいる。

---

## 結論

1. **法人で定額にできるのは、Claude・ChatGPT とも Premium（$125）が上限。** その先は、Claude Enterprise も ChatGPT のクレジットも従量課金になる。
2. **Gemini・GitHub Copilot は、この基準では得にならない。** 法人向けの席に含まれる量が、席料金と同額か、それ以下しかない。
3. **基準を満たす可能性があるのは Cursor Teams の Super 席（$100/席/月）だけ。** 法人向けの管理機能があり、個人向けと同じ段階の枠が付く。ただし枠で使えるのは Grok と Cursor 独自のモデルだけで、性能は Claude・Codex より一段下。量も数字で公開されていない。
4. **まず Cursor Teams Super を1席・月払いで1か月試し**、Codex Premium と比べてどれくらい作業できるかを測ってから判断する。使い方は、難しい作業は Claude・Codex に残し、軽い作業や数の多い作業を Cursor に逃がして Premium の枠を長持ちさせる形が前提。

## 2. Cursor Teams（唯一の候補）

出典: [Cursor: Models & Pricing](https://cursor.com/docs/models-and-pricing)（公式） / [toolcolumn: Grok Limits by Plan（10/29更新）](https://www.toolcolumn.com/learn/grok-usage-limits-by-plan)

- **料金と段階**: 1席あたり $30 / $100 / $200 の定額で、それぞれ Premium / Super / Ultra。個人向けの同じ段階と同じ料金・同じ量。1つのチームの中で、人ごとに違う段階の席を混ぜられる。
- **枠の中身**: 週ごとにリセットされる枠で、Grok 4.7・4.6・4.5 と Cursor 独自の Composer 2.5 を使える。週ごとなので、1日に使いすぎても1か月分が尽きることはない。
- **量**: Plus の何倍かで示されている（Premium 4倍、Super 15倍、Ultra 50倍）。具体的な回数やトークン数は公開されていない。チームの席どうしで枠は共有しない。
- **枠の対象外**: Claude・GPT・Gemini は枠に含まれない。API の定価に、Cursor の手数料（$0.25/100万トークン）を足した従量課金。チームで1つの前払い残高と上限額を管理する。
- **法人向けの機能**: 請求と管理の一元化、SAML / OIDC の SSO（シングルサインオン）、チーム全体へのプライバシーモードの強制、チャットの保存期間の設定、利用状況の分析、チームで共有するルールやスキル。SCIM（ID 管理システムとの自動連携）、請求書払い、席どうしで共有する枠は Enterprise（個別見積もり）のみ。
- **使う画面**: VS Code から派生した Cursor エディタと、Cursor の CLI。Teams の席で Grok Build の CLI を使えるかは、ドキュメントに書かれていない。
- **xAI との関係**: xAI の公式ドキュメントでも、Grok Bot は「Cursor のすべての有料プランに含まれる」とされ、チームの管理は Cursor の管理画面で行う（[Grok Bot for teams and enterprises](https://docs.x.ai/grok-bot/teams-and-enterprises)）。Grok と Cursor の料金体系は統合されている。

**懸念点**

- **性能**: FrontierCode 2.0（Cognition が10月に公開した、実際の PR をマージしてよいか判定させる難しいベンチマーク）では、Grok 4.7 が 28.6%。Opus 5.5（45.5%）や GPT-6 Astra（42.8%）に大きく劣る。Composer 2.5 の性能は確認していない。
- **量が事前に計算できない**: Codex のときのように「得かどうか」を事前に計算できない。試して測るしかない。
- **データの扱い**: Teams のデータが学習に使われるかは、料金ページには書かれていない。プライバシーモードを強制したうえで、プライバシーポリシーを確認する必要がある。

## 3. 得にならない、または使えない候補

### GitHub Copilot Business / Enterprise

- 料金は $19 / $39（席あたり月額）で、含まれる量はそれぞれ1,900 / 3,900 クレジット（1クレジット = $0.01、つまり席料金と同額分）。組織全体で共有し、使い切った後は同じ単価で追加できる。2026年6月に、プレミアムリクエストから AI クレジットに切り替わった（[BenchLM: GitHub Copilot Pricing](https://benchlm.ai/github-copilot/pricing)）。
- Opus 5.5・GPT-6 Astra・Gemini 4 Argon・Grok 4.7 などを1つの契約で使える（[GitHub Docs: 対応モデル](https://docs.github.com/en/copilot/reference/ai-models/supported-models)）。単価は API とほぼ同じ（例: Opus 5.5 は入力 $4 / 出力 $20、Grok 4.7 は $2 / $6、100万トークンあたり）。
- **席料金と同額分しか付かないので、Claude の超過利用を買うのと変わらない。** 割安になるのは個人向けの Pro+（$39 で $70 分）や Max（$100 で $200 分）だけ。

### Gemini（Antigravity）

- **個人向けの Pro / Ultra は法人では使えない。** Workspace 向けの「AI Ultra Access」アドオンは 2026年7月7日で提供終了。移行先の「AI Expanded Access」には、Antigravity などの開発者ツールが含まれない（[フォーラム: AI Ultra Access 終了後の開発者の扱い](https://discuss.ai.google.dev/t/clarification-needed-path-forward-for-developers-after-ai-ultra-access-retirement/170853) / [フォーラム: Ultra 終了後の Antigravity](https://discuss.ai.google.dev/t/antigravity-access-after-ai-ultra-plan-ends/170980)）。それ以前から、Workspace アカウントでは Antigravity が途中で止まるという報告が多かった（[フォーラム](https://discuss.ai.google.dev/t/bug-agent-terminated-error-makes-antigravity-completely-unusable-on-google-workspace-accounts-personal-accounts-work-fine/139683)）。
- **法人の入口は Google Cloud 経由の2つ**（[公式料金ページ](https://antigravity.google/pricing)）:
  - Gemini Enterprise Standard / Plus: $30/席/月〜。含まれる Antigravity の枠は1人あたり月 $10（Standard）/ $15（Plus）分だけで、チーム全体で共有し、7日ごとの上限で管理される。超えた分は管理者が許可すれば従量課金（[公式ドキュメント](https://docs.cloud.google.com/gemini/enterprise/docs/quotas-and-overages)）。
  - 従量課金のみのプラン: 席料金 $0。
- Antigravity を Gemini Enterprise に含める形は、まだ「対象の顧客」への提供（[Google Cloud ブログ、2026-08-27](https://cloud.google.com/blog/products/ai-machine-learning/flexible-billing-and-cost-controls-for-agents-on-google-cloud)）。
- プロジェクトごとの上限額や予算の通知など、従量課金の予算管理の仕組みは整っている。ただし定額ではない。

### Grok（xAI 直販）

- **SuperGrok・SuperGrok Plus は、2026年10月12日に新規の販売が終了した。** 新規の客は「The X Subscription」（Free / Plus $8 / Premium $30 / Super $100 / Ultra $200）で契約する。既存の契約者は当面そのまま使えるが、いずれ新しいプランへ移す予定（[aionx: SuperGrok Pricing 2026](https://aionx.co/ai-comparisons/supergrok-pricing-tiers-2026/) / [izzedo: How Much Does Grok Cost?](https://www.izzedo.chat/blog/how-much-does-grok-cost)）。いずれも二次情報。
- X Subscription の Super（$100）などは個人向けのプラン。法人として使うなら、Cursor Teams の同じ段階の席を使うほうが、管理機能が付く。
- **Grok Business**（約 $30/席/月、年契約なら $25）: 二次情報では、Grok Build を含み、標準で学習に使われず、SOC 2 Type II を取得しているとされる。1席あたりの量は公開されていない（[aipricing.guru](https://www.aipricing.guru/subscriptions/xai-grok-business/) / [TechRadar](https://www.techradar.com/pro/elon-musk-goes-all-in-on-smbs-with-new-grok-enterprise-and-business-offerings?rand=141) / [xAI FAQ](https://docs.x.ai/grok/faq)）。
- **Grok Enterprise**: 個別見積もり。

### Claude・ChatGPT の上位プラン

- Claude は Team Premium（月払い $125、年払い $100）が法人向けの定額の最上位。Enterprise は席料金と、API と同じ単価の従量課金（[Runbear](https://runbear.io/posts/claude-enterprise-pricing-mid-market) / [Redress Compliance](https://redresscompliance.com/anthropic-claude-pricing-2026.html)）。
- Team の超過利用は、組織全体と利用者ごとに上限額を設定でき、API と同じ単価で請求される（[Claude Team の料金](https://www.morphllm.com/claude-code-team-pricing) / [公式ヘルプ](https://support.claude.com/en/articles/9266767-what-is-the-team-plan)）。
- ChatGPT Business も Premium（$125）が上限で、その先は組織で共有するクレジット（[OpenAI の料金表](https://help.openai.com/en/articles/11481834-chatgpt-rate-card-business-enterpriseedu-credit-based-pricing)）。

## 4. 次にやること

1. **Cursor Teams Super を1席・月払いで1か月試す。** 普段 Codex に任せている作業のうち、軽いものや数の多いものを回し、週の枠がどれくらい減るかを測る。Codex Premium と比べて、何割分の作業ができるかで判断する。
2. あわせて、Cursor の **プライバシーモードを強制する設定と、データの扱いの条件**を確認する。
3. Claude・ChatGPT の Premium を年払いにできるなら、年払いにする（$125 → $100、20%引き）。浮いた分を3つ目の席に回せる。

## 調査上の限界

- Cursor Teams の各段階の量は「Plus の何倍か」しか公開されていない。Grok Business の量も非公開。
- Composer 2.5 の性能と、Teams の席で Grok Build の CLI を使えるかは確認していない。
- SuperGrok の販売終了、Grok Business の価格・内容、Gemini Enterprise Plus の価格は二次情報のみ。
- Workspace の AI Ultra Access 終了について、Google のヘルプページ本体は確認できていない。フォーラムに引用された告知と利用者の報告による。
- xAI の料金ページと利用規約は取得時に 403 で、個人向けプランを業務に使ってよいかの条文を確認できなかった。
